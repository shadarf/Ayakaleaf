### [21:15] MongoDB Version Fix
- Initial config had `MONGO_VERSION=7.0` → Failed validation
- Error: "Invalid MONGO_VERSION: MONGO_VERSION=7.0"
- **Fix**: Changed to `MONGO_VERSION=8.0` in config/overleaf.rc
- MongoDB 8.0 required for Ayakaleaf Pro (checked via healthcheck using mongosh)

### [21:20] read_configuration Function Fix
- Toolkit's `lib/shared-functions.sh` had broken `read_configuration` function
- Regex `s/^$name=(["']?)(.+)\1$/\2/` failed to parse values correctly
- Values read as `MONGO_VERSION=7.0` (with literal quotes) instead of `7.0`
- **Fix**: Replaced function with parameter expansion approach:
  ```bash
  line=${line#*=}
  line=${line#\"}; line=${line%\"}
  line=${line#'"'"'}; line=${line%'"'"'}
  echo "$line"
  ```
- Applied via sed replacement of entire function block

## lib/shared-functions.sh - read_configuration function (FIXED)
```bash
function read_configuration() {
  local name=$1
  local line
  line=$(grep -E "^$name=" "$TOOLKIT_ROOT/config/overleaf.rc")
  if [[ -z "$line" ]]; then
    return
  fi
  line=${line#*=}
  line=${line#\"}
  line=${line%\"}
  line=${line#'"'"'}
  line=${line%'"'"'}
  echo "$line"
}
```
